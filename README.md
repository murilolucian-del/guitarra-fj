# 🎸 Guitarra F·J

Jogo de ritmo no navegador: acerte as notas com as teclas **F** (esquerda) e **J** (direita) e toque a música na guitarra.

## Como jogar
- As notas descem pelas duas cordas. Aperte **F** ou **J** quando chegarem no círculo.
- Cada acerto toca a próxima nota da música com som de corda de guitarra (Karplus-Strong, via Web Audio).
- Errou ou deixou passar? A nota some e toca um "plunc" de corda abafada.
- No celular, use os botões F e J na tela.

## Músicas
Domínio público (Beethoven, Grieg, Pachelbel, Jingle Bells, Greensleeves, Parabéns pra Você etc.) e riffs originais.
Você também pode escrever a sua: notas como `E4 E4 F4*2 G4` ou números MIDI (`*2` = 2 tempos).

> Não inclua melodias protegidas por direitos autorais no repositório.

## Rodar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages
1. Suba o repositório no GitHub.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O jogo fica em `https://SEU-USUARIO.github.io/guitarra-fj/`.
